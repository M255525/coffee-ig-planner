# IG 內容規劃報告產生器

以「品牌顧問」視角規劃一個月（4 週、至少 12 篇）Instagram 內容的產生器網站，預設示範品牌為虛構的「晨光手沖咖啡」。

- 純前端單頁網站，無需安裝、無後端、無序號授權。
- 頁面上直接填品牌變數（名稱／標語／地點／客群…）按「產生」，免 AI 金鑰也能立刻套用到你的品牌。
- 選填 Claude／OpenAI／Gemini／OpenRouter 的 API 金鑰（BYOK，只存瀏覽器 localStorage），可請 AI 依你的品牌資訊重新生成完全客製的四週計畫；AI 失敗會自動退回範本套版，不會沒有內容。
