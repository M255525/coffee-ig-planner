操作手冊

以「品牌顧問」角色，依你填寫的品牌變數規劃一個月（4 週、至少 12 篇）的 Instagram 貼文內容。

操作步驟

  1. 上方「品牌變數」表單填品牌名稱、標語、地點、目前階段、經營型態、目標客群等資訊；也可以先點快速範例按鈕，套用一組虛構咖啡店範例再自行修改
  2. 沒有 AI 金鑰也沒關係：直接按「產生我的四週計畫」，會用內建範本把你填的品牌名稱換進既有的 13 篇貼文計畫
  3. 想要完全依你的品牌客製內容，可展開「AI 生成設定」，選擇服務商並填入你自己的 API 金鑰，再按「產生」——這次會請 AI 依你的品牌資訊重新生成一份專屬的四週計畫（AI 生成失敗時會自動退回範本套版，不會沒有內容）
  4. 不滿意想重來，按「重設為範例」可以還原成預設的「晨光手沖咖啡」示範內容
「給 AI 的補充描述」欄位只有在填了 API 金鑰、實際呼叫 AI 生成時才會用到；免 AI 金鑰的範本套版不會讀取這個欄位。

快速範例

表單上方有 5 個快速範例按鈕，都是虛構的咖啡／飲品店情境（不同經營型態與客群），方便快速上手或觀察不同變數組合會怎麼影響顧問筆記的措辭。點下去會直接覆蓋目前表單內容，若表單已經填過東西會先詢問是否確定覆蓋。

加入主畫面（可選）

頁尾按「📲 加入主畫面」，可以把這個工具像 App 一樣安裝到手機或電腦桌面，之後不用開瀏覽器輸網址就能直接點圖示開啟。

  • Android（Chrome）／桌面 Chrome、Edge：按下按鈕會直接跳出安裝確認視窗
  • iPhone／iPad（Safari）：按下按鈕會提示改用「分享」圖示 → 「加入主畫面」（iOS 系統限制，無法由網頁直接跳出安裝視窗）
  • Mac 桌面版 Safari：會提示改用選單列「檔案」→「加入 Dock」（Safari 17 以上）
安裝與否不影響任何功能，純粹是操作方便性；不安裝、直接用瀏覽器開網址一樣可以完整使用。

隱私說明

  • 你填寫的品牌變數與產生出來的四週計畫都只存在自己瀏覽器的 localStorage，關閉分頁後下次打開仍會保留，但不會傳送到任何伺服器；換一台電腦或清除瀏覽器資料就會不見
  • AI 金鑰同樣只存在瀏覽器的 localStorage；按下「產生」且有填金鑰時，你的品牌資訊會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器
  • 「重設為範例」會清除瀏覽器裡目前的品牌變數與生成內容，此動作無法復原

使用警語

請注意：
  • 本工具的範例與規則式套版內容皆為虛構示範，不代表任何真實店家；只有你主動填入 API 金鑰並按下「產生」時才會呼叫語言模型，不使用這項功能就完全不會連網
  • 請勿在任何欄位輸入真實個資、公司機密，或不希望被 AI 服務留存的敏感資訊
  • AI 生成的內容可能包含錯誤或不合時宜的建議，實際發布到社群前務必自行檢查與調整
  • 使用 AI 生成功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
  • 本工具與創作者不對使用產生內容後所得之任何 AI 輸出結果負責
